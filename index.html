بيانات دخول النظام

تغيير فوري
هذه بيانات حسابك الحالي. المدير يستطيع إدارة حسابات الموظفين من صفحة الموظفين، والموظف يرى ويغيّر بيانات حسابه فقط.

أجهزة الطباعة وقارئ الباركود

طباعة النظام
قارئات الباركود USB وBluetooth التي تعمل كلوحة مفاتيح تعمل مباشرة. الطباعة العادية تفتح نافذة طباعة الجهاز، وعند اختيار الطباعة الحرارية يتم الاتصال ببرنامج Print Agent المثبت على جهاز الكاشير.
يمكن الاتصال بالطابعة الحرارية عبر USB/Serial أو Bluetooth إذا كان المتصفح يدعم ذلك، أو عبر Print Agent للطابعات المثبتة على Windows.

درج النقود / الخزنة

دعم RJ11/RJ12 يكون عبر منفذ درج النقود في الطابعة الحرارية بإرسال أمر ESC/POS. وUSB/Serial المباشر يعمل إذا كان الدرج نفسه يظهر كمنفذ تسلسلي مدعوم من المتصفح. عند استخدام Print Agent يتم إرسال نبضة الفتح إلى الطابعة المحددة.
